# North Star Metric

## Objetivo

Escolher uma métrica líder que alinha produto, growth e operação ao valor real entregue — e usá-la para decidir o que importa agora.

Resolve empresas com 30 KPIs e zero direção compartilhada.

---

## Filosofia

- North Star mede valor entregue, não vaidade de funil.
- Uma métrica. Conta a história do negócio em uma linha.
- NSM não substitui finanças. Ela lidera comportamento; receita valida depois.
- Se a equipe não consegue ligar o trabalho diário à NSM, a métrica está errada ou a comunicação falhou.
- Contador bruto sem qualidade mente (MAU sem ativação, “mensagens enviadas” sem outcome).
- A NSM muda com estágio — mas não toda sprint.
- Inputs (alavancas) existem embaixo. NSM sem inputs vira torcida.
- O que você escolhe como estrela, a organização otimiza — para o bem ou para o game.

---

## Framework

### 1. Critérios de uma boa NSM

Deve ser:

1. **Valor**: sobe quando o cliente recebe o job feito
2. **Acionável**: times sabem o que mover
3. **Compreensível**: qualquer um explica em 10 segundos
4. **Leading**: antecipa retenção/receita (não só espelho atrasado)
5. **Difícil de gamear** sem entregar valor de verdade

### 2. Escolha pelo job do produto

| Negócio | NSM típica (exemplos) |
|---------|------------------------|
| SaaS colaborativo | # times com core action semanal |
| Marketplace | # transações concluídas / GMV de qualidade |
| Consumer habit | # usuários com streak / frequência core |
| IA workflow | # jobs concluídos com qualidade aceita |
| B2B high-touch | # contas no health verde + expanding |

Evite: pageviews, signups, downloads isolados, “engajamento” sem definição.

### 3. Monte a árvore de inputs

```
North Star
        ↓
Input A (aquisição → ativação)
        ↓
Input B (frequência / profundidade)
        ↓
Input C (retenção / expansão)
```

Cada squad dono de 1–2 inputs. NSM é compartilhada; inputs são responsabilidades.

### 4. Ritual de uso

- Dashboard diário/semanal com NSM + 3–5 inputs
- Toda initiative responde: “como move a NSM ou um input?”
- Review mensal: a métrica ainda reflete valor? Estamos gaming?

### 5. Guardrails

Pareie a NSM com contra-métricas:

| NSM sobe, mas… | Olhe |
|----------------|------|
| Qualidade cai | Churn, CSAT, error rate |
| Margem some | Custo por unidade de valor (ex.: $/job IA) |
| Só power users | % usuários abaixo do threshold |
| Aquisição lixo | Ativação e retenção do cohort |

### 6. Quando trocar

Troque se:

- Modelo de negócio mudou
- Métrica saturou ou virou fácil de gamear
- Empresa saiu de PLG puro para enterprise (ou o inverso)

Documente a troca. Não “muda a estrela” por trimestral de ego.

## Aplicações

### SaaS

Prefira “contas ativas no core” a seats vendidos. Seats sem uso incham e churnam.

### IA

Jobs concluídos / workflows aceitos pelo usuário. Tokens consumidos sozinhos são custo, não valor.

### Empresas B2B

Accounts com adoção multi-user + outcome. Logo count sem usage é mentira elegante.

### Produtos Digitais

Core action na frequência natural (diária/semanal). MAU sem frequência esconde decay.

### Startups

Uma NSM escrita na parede. Se o time discorda o que é “sucesso da semana”, pare e alinhe.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| NSM = revenue | Reação lenta, silos | Valor + inputs de uso |
| 12 “north stars” | Nenhuma direção | Uma líder |
| Sem inputs | Torcida | Árvore de alavancas |
| Gaming óbvio | Inflação | Guardrails |
| Copiar NSM do Notion/Slack | Job errado | Derive do seu core |
| Trocar toda hora | Amnésia | Cadência de revisão |

---

## Checklist

- [ ] NSM cabe em uma frase e mede valor
- [ ] Time inteiro sabe o que é e por quê
- [ ] 3–5 inputs donos definidos
- [ ] Dashboard vivo (não slide mensal só)
- [ ] Guardrails de qualidade/margem existem
- [ ] Initiatives amarradas à NSM/inputs
- [ ] Difícil gamear sem entregar valor
- [ ] Revisada por estágio (não por humor)
- [ ] Couples com retenção/receita em review
- [ ] Canais e features julgados pelo impacto na NSM

# Growth Loops

## Objetivo

Desenhar crescimento como ciclo que se alimenta — output de um turno vira input do próximo — em vez de depender só de gasto contínuo em aquisição linear.

Resolve a armadilha das “campanhas” que morrem quando a verba ou o hero para.

---

## Filosofia

- Funis vazam. Loops acumulam.
- Todo loop precisa de uma moeda: usuário, conteúdo, data, capital, reputação.
- Loop fraco + paid pode funcionar no curto prazo. Loop forte reduz dependência de paid.
- Viralidade forçada (spam) destrói marca. Viralidade por valor dura.
- Meça o coeficiente e o tempo do ciclo. Loop lento demais não financia o negócio.
- Cresça o loop que traz o usuário certo — não qualquer volume.
- Produto é o motor; marketing é combustível e lubrificante. Sem motor, combustível queima.
- Um loop bem operado > cinco half-baked.

## Framework

### 1. Anatomia de um loop

```
Input (usuário / conteúdo / $)
        ↓
Ação core
        ↓
Output de valor
        ↓
Reinvestimento (invite, share, SEO, $ reinvestido)
        ↓
Mais input
```

Sem reinvestimento explícito, você tem funil, não loop.

### 2. Tipos de loop (escolha o principal)

| Loop | Mecânica | Exemplo de reinvestimento |
|------|----------|---------------------------|
| Viral / referral | Usuário traz usuário | Invite com valor mútuo |
| Content | Conteúdo atrai → mais conteúdo/prova | UGC, cases, templates públicos |
| Sales | Receita → reinveste em outbound/SDR | $ → mais pipeline → $ |
| Paid | Receita → ads → usuários → receita | Só sustentável com unit economics |
| Data | Uso melhora produto → mais uso | Modelos, rankings, personalização |
| Network | Densidade aumenta valor → atrai mais | Marketplaces, collab |
| Collaboration | Trabalho conjunto puxa colegas | Seats, shared workspaces |

### 3. Desenhe o loop em uma página

Responda:

1. Quem entra?
2. Qual ação gera valor rápido?
3. O que é emitido (link, artifact, invite, review)?
4. Por que o próximo humano age?
5. Quanto tempo leva uma volta?
6. Qual % completa o ciclo?
7. Qual qualidade do usuário gerado?

### 4. Otimize na ordem certa

```
Valor core (retention do job)
        ↓
Momento de trigger do loop
        ↓
Incentivo / fricção do share-invite
        ↓
Destino de aterrissagem
        ↓
Ativação do novo usuário
        ↓
Instrumentação do coeficiente
```

Otimizar share buttons antes do aha é cosmético.

### 5. Métricas do loop

- Conversion em cada etapa do ciclo
- Cycle time
- K-factor ou equivalente (invites aceitos úteis)
- % de aquisição vinda do loop vs paid
- Retenção da coorte gerada pelo loop

### 6. Quando usar paid

Paid é acelerador:

- Dentro de unit economics
- Direcionado ao ICP
- Sem mascarar buraco de retenção

Paid infinito sem loop owned = risco estrutural.

## Aplicações

### SaaS

Templates públicos, “built with”, referral de workspace, SEO de páginas de recurso. Collab loop (convidar colega para o doc/board).

### IA

Output compartilhável (relatório, imagem, plano) com CTA de “criar o seu”. Data loop: feedback humano melhora qualidade no job.

### Empresas B2B

Content + partner loop; sales loop só com payback saudável. Champion leva para outro departamento (land and expand como loop interno).

### Produtos Digitais

Invite com benefício mútuo, UGC, leaderboards só se genuínos. Evite dark patterns de viralidade.

### Startups

Escolha 1 loop alinhado ao produto. Instrumente. Melhore cycle time. Ignore o hype do loop da moda.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Chamar funil de loop | Dependência eterna de input | Desenhar reinvestimento |
| Viral sem valor | Uninstall / hate | Aha primeiro |
| Muitos loops | Nenhum anda | 1 loop core |
| Ignorar qualidade | Crescimento oco | Cohorts por origem |
| Pagar por crescimento cego | Burn | Unit economics + retenção |
| Não medir cycle time | Ilusão | Instrumentar etapas |

---

## Checklist

- [ ] Loop core desenhado em 1 página
- [ ] Reinvestimento está explícito
- [ ] Ativação ao valor ocorre antes do ask de share/invite
- [ ] Etapas instrumentadas
- [ ] Cycle time conhecido
- [ ] Qualidade do usuário do loop é aceitável
- [ ] % de aquisição via loop está crescendo ou está no plano
- [ ] Paid só acelera unit economics saudáveis
- [ ] Loop alinhado a ICP e posicionamento
- [ ] Review mensal das taxas de conversão do ciclo

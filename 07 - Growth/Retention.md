# Retention

## Objetivo

Fazer usuários e clientes voltarem e permanecerem — porque o valor core entrou na rotina — protegendo LTV e tornando aquisição rentável.

Resolve o crescimento ilusório: entram muitos, saem quase todos, marketing aplaude o topo do funil.

---

## Filosofia

- Retenção é o primeiro crescimento. Sem ela, aquisição é vazamento.
- Pessoas não “esquecem” o produto. Elas decidem que não era prioridade.
- Time-to-value curto muda retenção mais que feature volume.
- Churn é feedback atrasado. Ativação fraca é o crime anterior.
- Habit loops e switching costs saudáveis > lock-in hostil.
- Segmente retenção. A média mente.
- Salvar conta com desconto eterno treina churn por barganha.
- CS e produto compartilham a métrica. Culpa isolada não resolve.

## Framework

### 1. Defina retenção do seu negócio

| Tipo | O que medir |
|------|-------------|
| SaaS B2B | Logo churn, revenue churn, NRR |
| PLG / consumer | D1 / D7 / D30, WAU/MAU, core action rate |
| Usage | % usuários acima do threshold de valor |

Escolha a **core action** — o comportamento que correlaciona com “recebeu valor”.

### 2. Mapeie a jornada até o hábito

```
Signup
    ↓
Setup mínimo
    ↓
Aha (primeira vitória)
    ↓
Habit (repetição no período natural)
    ↓
Habit + expanding value
    ↓
Advocate / expand
```

Meça drop-off em cada degrau. O maior buraco é a prioridade.

### 3. Diagnóstico de churn

Categorias típicas:

1. **Never activated** — não chegou no aha
2. **Activated then decay** — valor não entrou na rotina
3. **Value mismatch** — ICP errado / overpromise
4. **Competitive replace** — rival ganhou o job
5. **Forced** — empresa morreu, budget cut, sponsor saiu

Cada categoria pede remédio diferente. Tratar tudo com “mais email” é amador.

### 4. Alavancas na ordem correta

1. **Produto**: reduzir fricção até o aha; confiabilidade; core loop diário/semanal
2. **Onboarding**: checklist, empty states, templates, setup assistido se ACV pagar
3. **Lifecycle**: nudges no momento certo (não spam)
4. **Success**: para ACV alto — QBR, health scores, training
5. **Packaging**: limites que empurram upgrade sem sabotagem

### 5. Health score simples

Sinais (exemplos):

- Uso da core action na frequência esperada
- Seats ativos / expansões
- Integrações críticas ligadas
- Tickets de suporte (volume + severidade)
- Champion engagement

Vermelho → intervenção. Verde → pedir expansão/indicação.

### 6. Ritual operacional

- Cohort review semanal (produto + growth)
- Win/loss + churn interviews (amostra)
- Top 3 causas → top 3 apostas do mês
- NRR / churn no dashboard de liderança (não enterrado)

## Aplicações

### SaaS

Activation metric #1 no KPI company-wide. Empty states com templates. Emails de lifecycle amarrados a eventos de produto, não calendário cego.

### IA

Retenção = qualidade consistente no workflow + custo previsível. Se a mágica falha 30% das vezes, churn é racional.

### Empresas B2B

Multi-thread (não depender de um champion). Time-to-first-value no piloto. Treinamento do time do cliente.

### Produtos Digitais

Notificações só quando aumentam retorno ao core. Caso contrário, desinstalação.

### Startups

Fale com churned toda semana. Padronize motivos. Conserte o buraco maior antes de escalar ads.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Escalar paid com retenção ruim | Burn | Congelar escala, consertar aha |
| Olhar só churn agregado | Cegueira | Cohorts + segmentos |
| Feature spam para reter | Complexidade | Fortalecer job core |
| Desconto anti-churn eterno | Margem e hábito de barganha | Fix valor; use desconto raro |
| CS heroico sem produto | Custo linear | Levar aprendizado ao roadmap |
| Lock-in sujo | Ódio + churn na janela | Valor + dados portáveis |

## Checklist

- [ ] Core action está definida e instrumentada
- [ ] Cohorts são revisados em cadência
- [ ] Time-to-aha está medido e sob pressão de melhoria
- [ ] Principais causas de churn estão categorizadas
- [ ] Onboarding leva ao valor sem heroics
- [ ] Health signals existem para contas importantes
- [ ] NRR / retenção está no radar da liderança
- [ ] Aquisição não escala acima do que retenção aguenta
- [ ] Entrevistas com churned acontecem de fato
- [ ] Expansão é pedida em contas saudáveis

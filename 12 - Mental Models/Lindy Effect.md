# Lindy Effect

## Objetivo

Usar a longevidade de ideias, práticas e tecnologias como prior de robustez — o que já sobreviveu ao tempo tem chance maior de continuar útil — sem virar nostalgia anti-inovação.

Resolve moda e hype tratados como fundação, e “novo” confundido com “melhor”.

---

## Filosofia

- Para não-perecíveis (ideias, livros, protocolos), expectativa de vida futura cresce com idade vivida.
- Hype recente tem alta taxa de mortalidade.
- Lindy é heurística, não lei física em tudo (produto perecível é outra lógica).
- Fundações do negócio devem enviesar para o Lindiano.
- Experimente o novo na borda; estabilize o core no testado.
- Longevidade com performance > longevidade por inércia institucional.
- Pergunte: isso ainda faz sentido se o hype sumir?
- Combine Lindy com first principles — idade ≠ verdade, mas é evidência.

## Framework

### 1. Quando aplicar

| Domínio | Lindy útil? |
|---------|-------------|
| Princípios de pricing, incentivos, copywriting | Sim |
| Protocolos, SQL, HTTP, e-mail | Sim |
| Frameworks JS do mês | Não como fundação |
| Modelos de negócio B2B testados | Sim com adaptação |
| Features cosméticas de UI | Pouco |
| Compliance / contratos | Sim |

### 2. Protocolo de escolha

```
Decisão de fundação (core)
        ↓
Opção nova vs opção Lindiana
        ↓
A nova tem vantagem estrutural clara?
        ↓
Não → prefira Lindiana
Sim → adote com rollback e mediçao
```

### 3. Portfólio temporal

1. **Core**: tecnologias e processos Lindianos
2. **Adjacent**: novas com optionality
3. **Scan**: hype monitorado sem compromisso

### 4. Anti-Lindy consciente

Às vezes o novo invalidou a premissa (IA em certos workflows). Exija evidência forte, não FOMO.

### 5. Perguntas checklist

- Isso existia e funcionava 5–10 anos atrás?
- O “novo” resolve uma restrição real ou só narrativa?
- Qual o custo de reverter?
- Estamos apostando o core ou a borda?

## Aplicações

### SaaS

Cobrança, e-mail, CRM basics, onboarding humano — princípios Lindianos com UX moderna.

### IA

Modelos mudam; evals, human feedback, unit economics e UX de workflow são mais Lindianos do que a marca do LLM do mês.

### Empresas B2B

Relacionamento, confiança, ROI mensurável — mais Lindy que grow-hacks passageiros.

### Produtos Digitais

Distribuição: SEO, comunidades, parcerias costumam outlast ads virais.

### Startups

Stack: prefira boring technology no core; innove no problema do cliente.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Hype no core | Reescrita eterna | Lindy no foundation |
| Lindy como dogma | Ficar para trás | First principles + evidência |
| Confundir idade com qualidade | Mediocridade | Performance + sobrevivência |
| Adotar tudo novo | Fragilidade | Portfólio temporal |
| Ignorar switching cost | Lock-in caro | Rollback planejado |
| Copiar big tech cedo | Complexidade | Estágio-apropriado |

## Checklist

- [ ] Decisão é core ou borda?
- [ ] Alternativa Lindiana considerada
- [ ] Vantagem do novo é estrutural?
- [ ] Custo de reverter estimado
- [ ] Métrica de sucesso do experimento
- [ ] Boring tech no path crítico quando possível
- [ ] Hype separado de fundação
- [ ] Princípios de negócio revisados
- [ ] Time alinhado no porquê
- [ ] Revisão após ciclo de hype
- [ ] Combinado com first principles
- [ ] Documentado na decisão

# Feedback Loops

## Objetivo

Enxergar e desenhar ciclos onde saídas voltam a influenciar entradas — reforçando ou equilibrando o sistema — para acelerar aprendizado e evitar spirals destrutivas.

Resolve ações tratadas como eventos isolados, quando na verdade elas treinam clientes, time e mercado a responder de certo modo.

---

## Filosofia

- Loop > linha: negócios são sistemas com retorno.
- Loops de reforço criam crescimento ou colapso.
- Loops de equilíbrio estabilizam (às vezes cedo demais).
- Delay no feedback é onde a intuição falha.
- Instrumentar o loop é condição de gestão moderna.
- Incentivos são o “código” do loop humano.
- Bom produto cria loop virtuoso; atalho cria vicioso.
- Encurtar o ciclo de aprendizado é vantagem competitiva.

## Framework

### 1. Tipologia

| Tipo | Comportamento | Exemplo |
|------|---------------|---------|
| Reforço (+) | Mais gera mais | Virality, data network |
| Equilíbrio (−) | Empurra à meta | Churn save, pricing cap |
| Atraso | Efeito vem tarde | Brand, SEO, NRR |

### 2. Mapa de um loop

```
Ação / métrica
        ↓
Resultado observado
        ↓
Interpretação
        ↓
Ajuste de comportamento
        ↓
(volta) Ação
```

Escreva explicitamente o que é reforçado.

### 3. Loops clássicos de negócio

1. **Produto–retenção–referência**
2. **Vendas–customização–complexidade–ciclo**
3. **Desconto–expectativa–margem**
4. **Hiring urgente–qualidade–mais urgência**
5. **Data–modelo–melhor produto–mais data** (IA)
6. **Suporte–dívida–mais suporte**

### 4. Desenho intencional

Para cada aposta:

1. Qual loop queremos reforçar?
2. Qual loop vicioso estamos alimentando?
3. Qual delay existe e como instrumentar canários cedo?
4. Qual alavanca (preço, UX, incentivo, política) muda o sinal?

### 5. Acelerar aprendizado

- Ciclos curtos de ship/measure
- Cohorts, não só totais
- Qual + quant
- Fechar o loop no Weekly Review

## Aplicações

### SaaS

Activation loop: first value → habit → expansion. Quebre fricção no caminho crítico.

### IA

Data flywheel só existe se o produto gera dados proprietários e melhora perceptível — senão é slide.

### Empresas B2B

Forecast e comportamento de sellers: meta agressiva sem qualidade cria loop de discount e churn.

### Produtos Digitais

Notification loops: engajamento de curto prazo pode destruir retenção de longo.

### Startups

Converse com clientes em ritmo semanal — loop de verdade antes de dashboard sofisticado.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Pensar linear | Surpresa sistêmica | Mapear o retorno |
| Ignorar delay | Overcorrection | Canários antecipados |
| Otimizar métrica errada | Loop vicioso | Amarre a valor |
| Loop só no slide | Nenhuma instrumentação | Medir o ciclo |
| Culpar pessoas | Loop persiste | Mudar incentivo/estrutura |
| Feedback lento demais | Aprender tarde | Encurtar ciclo |

---

## Checklist

- [ ] Loop nomeado (reforço ou equilíbrio)
- [ ] Variáveis e setas escritas
- [ ] Delay estimado
- [ ] Canários definidos
- [ ] Incentivos alinhados ao loop desejado
- [ ] Instrumentação no lugar
- [ ] Review no ritmo certo
- [ ] Loop vicioso concorrente listado
- [ ] Alavanca de intervenção clara
- [ ] Cohorts quando relevante
- [ ] Weekly fecha o aprendizado
- [ ] Ligado à aposta do trimestre

# Circle of Competence

## Objetivo

Saber o que você (e a empresa) realmente entendem — e operar com humildade fora desse círculo — para tomar decisões melhores e evitar arrogância cara.

Resolve entradas em mercados, stacks e apostas onde o time não tem edge e chama isso de “aprendizado” tarde demais.

---

## Filosofia

- Competência é demonstrável (track record, modelos mentais testados), não desejo.
- O tamanho do círculo importa menos que conhecer a borda.
- Fora do círculo: ou aprenda barato, partner, ou diga não.
- Expandir o círculo é possível — com rigor, tempo e feedback.
- Ego empurra para fora; incentivos alinhados puxam para dentro.
- Competência do founder ≠ competência do time atual.
- “Não sei” é ativo operacional quando verdadeiro.
- Nicho profundo costuma vencer generalismo raso em B2B/SaaS.

## Framework

### 1. Mapear o círculo

Liste domínios e marque:

| Domínio | Dentro | Borda | Fora |
|---------|--------|-------|------|
| ICP / mercado | | | |
| Pricing / packing | | | |
| Tech core | | | |
| Distribuição | | | |
| Financas / legal | | | |

**Dentro**: já ganhamos e entendemos por quê.  
**Borda**: hipótese com dados parciais.  
**Fora**: opinião sem prática.

### 2. Regras de decisão por zona

```
Dentro → mover rápido com ownership
        ↓
Borda → experimento barato + mentor/dado
        ↓
Fora → não, partner, contratar, ou aprender com budget/timebox
```

### 3. Expandir com método

1. Defina skill/mercado alvo
2. Timebox (ex.: 6–8 semanas)
3. Critérios de “agora estou na borda/dentro”
4. Projetos pequenos com feedback real
5. Só então subir aposta de capital

### 4. Sinais de fora do círculo

- Confiança alta sem casos concretos
- Dependência total de narradores externos
- Surpresas básicas repetidas (churn reasons, unit economics)
- Time não consegue explicar a aposta em 1 página

### 5. Uso em hiring e partnership

Contrate ou faça partnership para cobrir fora do círculo crítico — não para decorar organograma.

## Aplicações

### SaaS

Edge em um ICP > “plataforma para todos”. Recuse vertical que você não entende de verdade.

### IA

Saber dados, evals e workflow do usuário importa mais que paper-chasing. Não finja research lab se é app.

### Empresas B2B

Venda consultiva só onde domínio existe; senão demos viram teatro e churn sobe.

### Produtos Digitais

Canais e cultura do público: se não há sensibilidade, research antes de scale.

### Startups

Founders devem ser brutais: o que é unevenly great? Foque nisso no early stage.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Círculo de desejo | Queima de caixa | Exigir evidência |
| Nunca expandir | Estagnação | Timebox de aprendizado |
| Expandir sem método | Dilettantismo | Critérios + feedback |
| Confundir smart com competent | Blind spots | Track record |
| Outsource do core | Perda de edge | Core dentro; outsource commodity |
| Vergonha de “não sei” | Decisão ruim | Tornar explícito |

---

## Checklist

- [ ] Mapa dentro/borda/fora atualizado
- [ ] Decisão classificada na zona correta
- [ ] Fora do círculo tem plano (não/partner/hire/learn)
- [ ] Expansão com timebox e critérios
- [ ] Core edge protegido
- [ ] Hiring alinhado a gaps reais
- [ ] ICP coerente com competência
- [ ] 1-pager da aposta existe
- [ ] Feedback loops para testar competência
- [ ] Ego checado na borda
- [ ] Revisão trimestral do mapa
- [ ] Time compartilhou o mapa

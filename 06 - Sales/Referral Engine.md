# Referral Engine

## Objetivo

Transformar clientes e redes satisfeitos em fonte previsível de novos pipelines — com pedido sistemático, não “se quiserem indicar”.

Resolve esperar indicação mágica, pedir cedo demais (antes do valor), e programas de referral que ninguém usa.

---

## Filosofia

- Indicação é consequência de valor + relacionamento + pedido claro.
- Melhor CAC costuma nascer de referral — trate como canal, não sortimento.
- Peça no pico de satisfação (aha, win, QBR verde), não no onboarding dia 1.
- Torne o ato de indicar ridiculamente fácil (intro template, link, incentive).
- Incentive alinhado: crédito, doação, acesso — não bribe que atrai lead lixo.
- NPS alto sem ask = ego. Ask sem valor = constrangimento.
- Fundadores têm rede: use com disciplina e reciprocidade.
- Referral qualificado > volume de cupons públicos.

## Framework

### 1. Momentos de pedidos (triggers)

| Momento | Por quê |
|---------|---------|
| First value / aha | Emoção positiva fresca |
| Meta atingida / win documentado | Prova viva |
| Renewal / expansão feliz | Confiança alta |
| Elogio espontâneo / NPS 9–10 | “Você mencionou…” |
| Case study publicado | Orgulho social |

Evite pedir quando ticket vermelho ou adoção fraca.

### 2. O ask perfeito (estrutura)

```
1. Contexto do valor: “Vocês conseguiram X…”
2. Pedido específico: “Conhece 1–2 heads de Y em empresas Z?”
3. Facilidade: “Posso mandar um blurb de 3 linhas para você encaminhar?”
4. Baixa pressão: “Se não tiver ninguém agora, tudo bem.”
```

Específico > “conhece alguém que se beneficiaria?”.

### 3. Motor operacional

| Peça | Função |
|------|--------|
| CRM campo “referral source / ask date” | Tracking |
| Lista de promotores (NPS/health) | Prioridade |
| Cadência CS/AE de ask | Ritual mensal |
| Template de intro double-opt | Reduz atrito |
| Incentives (opcional) | Empurra sem poluir |
| SLA de follow-up no indicado | Respeito ao indicador |

Sem ritual, referral morre no “lembramos depois”.

### 4. Programa vs. 1:1

- **1:1 high-touch**: mid/enterprise — intro pessoal, CSM/AE
- **Programa público**: SMB/PLG — link, crédito mútuo, dashboard simples

Comece 1:1 até ter volume; só então productize.

### 5. Qualidade do indicado

Filtre:

- ICP do indicador costuma indicar ICP (ensine o perfil)
- Double opt-in evita surpresa
- AE trata indicado como VIP de confiança — não como cold

Queime um indicador com mau follow-up e a fonte seca.

### 6. Métricas

- % contas verdes pedidas / mês
- Asks feitos → intros → meetings → won
- CAC e win rate de referral vs. outros canais
- Tempo até first value do referred (deve ser rápido)

## Aplicações

### SaaS

CSM ask no QBR. In-app “indique e ganhe crédito” no plano certo. Customer advisory board como rede de intros.

### IA

Indicação entre peers de ops/engineering. Peça após win mensurável (“reduzimos X horas”). Cuidado com incentivo que gera tire-kickers de API.

### Empresas B2B

Intro peer-to-peer entre executives. Eventos privados de clientes. Parceiros (consultorias) como referral machine com regra de engajamento.

### Produtos Digitais

Referral no produto (doubling invite). Creators/afiliados se ACV/LTV pagar. Viral loops só com valor real.

### Startups

Fundador lista 30 clientes/contatos felizes → ask semanal. Documente intros. Isso financia o runway melhor que ads prematuros.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Nunca pedir | Zero volume | Ritual + triggers |
| Pedir cedo demais | Constrangimento | Após valor |
| Ask vago | Intros ruins | Perfil específico |
| Sem follow-up VIP | Fonte seca | SLA no indicado |
| Incentive só caçador | Leads lixo | Qualificar + alinhar |
| Programa complexo | Adoção zero | Simplicidade |

---

## Checklist

- [ ] Triggers de ask estão definidos
- [ ] Script/template de intro existe
- [ ] Contas promotoras são listadas e pedidas em cadência
- [ ] CRM rastreia referral até won
- [ ] Indicação recebe tratamento prioritário
- [ ] Incentive (se houver) não polui ICP
- [ ] CS e sales sabem quem pede e quando
- [ ] Double opt-in ou blurb fácil está pronto
- [ ] Métricas de referral no review de canais
- [ ] Cases e elogios viram combustível de ask

## Modelo Mental

```
Valor entregue
      ↓
Satisfação / status
      ↓
Ask específico + fácil
      ↓
Intro de confiança
      ↓
Follow-up impecável
      ↓
Won → novo promotor
```

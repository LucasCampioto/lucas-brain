# Storytelling

## Objetivo

Usar narrativa para tornar oferta, mudança e prova memoráveis — de modo que o ICP sinta a história, veja a si nela e avance para ação.

Resolve pitches de feature dump que ninguém lembra na hora da decisão.

---

## Filosofia

- Pessoas lembram histórias; esquecem listas de features.
- Narrativa boa não é ficção enganosa — é verdade estruturada.
- Herói é o cliente (ou o mercado). Sua empresa é guia/arma, não o salvador narcisista.
- Tensão sem resolução é drama barato; resolução sem tensão é brochure.
- Especificidade cria crença. Abstração cria esquecimento.
- Uma empresa precisa de narrativa mãe + histórias filhas (cases, launches, posts).
- Storytelling sem CTA é cinema; CTA sem story é pressa.
- Repita a narrativa até o mercado poder recontá-la.

---

## Framework

### 1. Narrativa mãe (posicionamento em arco)

Estrutura clássica de mercado:

```
Como o mundo funciona hoje (status quo)
        ↓
Por que isso falha / custa caro (tensão)
        ↓
O insight / mudança de jogo
        ↓
O novo caminho (sua categoria / método)
        ↓
Prova de que funciona
        ↓
Convite à ação
```

Se qualquer etapa for genérica, a história não gruda.

### 2. Arco do comprador (story de conversão)

| Beats | Conteúdo |
|-------|----------|
| Mundo ordinário | Rotina quebrada do ICP |
| Incidente | Trigger (escala, crise, deadline) |
| Dúvida | Já tentou X e falhou |
| Guia | Você / método com autoridade |
| Plano | Passos claros (não 40 features) |
| Stakes | Custo de não mudar |
| Sucesso | Resultado concreto |
| Transformação | Identidade nova (“times que…”) |

### 3. Case story (prova narrativa)

Template:

1. Contexto do cliente (ICP reconhecível)
2. Problema com custo
3. Tentativas anteriores
4. Decisão / por que vocês
5. Implementação (honesta)
6. Resultado mensurável
7. Lição transferível
8. CTA (“veja se combina com…”)

Sem número ou evidencia, é anedota fraca — ainda pode servir se o mecanismo for claro.

### 4. Story em formatos curtos

| Formato | Beat essencial |
|---------|----------------|
| Post | Tensão + insight + prova em miniatura |
| Assunto de email | Curiosidade específica |
| Landing hero | Promessa + para quem + tensão implícita |
| Demo | Antes → durante → depois |
| Pitch deck | Arco mãe em 5–7 slides |
| Ad | Hook = tensão; body = resolução |

Mesmo arco. Compressão diferente.

### 5. Regras de verdade

- Não invente métricas
- Inclua tradeoffs (aumenta confiança)
- Nomeie o inimigo (processo/crença), não difame pessoa
- Mostre o “meio” feio do building quando for authenticity real
- Separe aspiração de claim factual

### 6. Teste de memorabilidade

Peça para um outsider retellar em 30 segundos:

- Qual problema?
- Qual mudança?
- Por que vocês?
- O que fazer agora?

Se travar, a história ainda não está pronta.

## Aplicações

### SaaS

Narrativa de categoria + cases de jobs. Onboarding como história (primeira vitória). Changelog com “o que muda no dia a dia”.

### IA

Histórias de workflow (input → medo → output → decisão). Mostre falha e correção — confiança narrativa. Evite sci-fi hype.

### B2B

Story para champion (dor operacional) e buyer (risco/ROI). Multi-thread no buying committee. RFPs: narrativa + proof appendix.

### Produtos Digitais

Before/after do usuário. Origin story do produto só se servir o ICP. UGC stories > brand fiction.

### Startups

Founder story curta (por que este problema). Customer discovery vira content story. Pitch: arco mãe nítido em 2 minutos.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Empresa como herói | Ego, baixa conexão | Cliente no centro |
| Feature dump | Esquecimento | Arco + stakes |
| Clickbait vazio | Desconfiança | Especificidade + prova |
| História única genérica | Não cola no ICP | Detalhe de ofício |
| Mentira / inflate | Queima | Verdade estruturada |
| Sem CTA | História órfã | Convite claro |
| Mudar narrativa toda semana | Confusão | Narrativa mãe estável |

## Checklist

- [ ] Narrativa mãe escrita em 1 página
- [ ] Status quo, tensão, insight, caminho, prova, CTA
- [ ] Cases no template de prova narrativa
- [ ] Landing e pitch usam o mesmo arco
- [ ] Formatos curtos comprimem (não contradizem)
- [ ] Métricas e claims verificáveis
- [ ] Outsider consegue retellar
- [ ] Alinhado a Positioning e Visibility Engine
- [ ] Storytelling alimenta Content Engine
- [ ] Oferta encaixa no final do arco

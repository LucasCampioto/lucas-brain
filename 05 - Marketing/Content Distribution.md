# Content Distribution

## Objetivo

Transformar uma peça forte de conteúdo em dezenas de ativos úteis — em canais, formatos e momentos diferentes — sem reinventar a tese toda semana.

Resolve o ciclo “produzi, publiquei uma vez, morreu no feed”.

---

## Filosofia

- Distribuição vence produção. Uma ideia bem espalhada > dez ideias órfãs.
- O pilar é o ativo. Os átomos são a distribuição do ativo.
- Não “recicle por obrigação”. Adapte intenção, ângulo e CTA ao canal.
- Algoritmo recompensa consistência de sinal; humano recompensa especificidade.
- Owned (email, hub, lista) é o banco. Rented (feed, ads) é o caixa.
- Cada peça deve apontar para um próximo passo mensurável.
- Volume sem tese dilui marca. Volume com tese acelera presença mental.
- Distribuição sem medição é hobby; com medição é sistema.

---

## Framework

### 1. Comece pelo pilar (não pelo post)

Pilar típico (escolha um por ciclo):

- Essay / playbook longo
- Vídeo 8–20 min
- Webinar / AMA gravado
- Case profundo
- Framework original em PDF/Notion

Critério: é específico o suficiente para o ICP e profundo o suficiente para virar 10+ derivados?

### 2. Motor de derivação (1 → N)

```
1 pilar
   ↓
Extrair: tese, 3 insights, 1 história, 1 dado, 1 CTA
   ↓
Formatos
   ├─ 5–10 posts curtos (ângulo diferente cada)
   ├─ 1–3 carrosséis / threads
   ├─ 3–8 clips / shorts
   ├─ 1 newsletter (síntese + link)
   ├─ 1 post de blog SEO (se o pilar não for SEO)
   ├─ 1 lead magnet (checklist/template)
   └─ 2–5 respostas em comunidades / comentários
   ↓
Agendar por canal (não dump no mesmo dia)
   ↓
Medir → dobrar formatos que trazem ICP
```

Regra prática: se o pilar não gera pelo menos **8 derivados**, a peça era rasa ou você não extraiu direito.

### 3. Matriz canal × intenção

| Canal | Intenção | Formato que funciona |
|-------|----------|----------------------|
| LinkedIn | Autoridade B2B | Stories, opinião, teardown |
| X / Twitter | Velocidade de ideia | Thread, hot take com nuance |
| Instagram | Prova visual + pessoa | Carrossel, Reels, bastidor |
| YouTube | Busca + profundidade | Longo + Shorts derivados |
| TikTok | Alcance / curiosidade | Hook forte, demos rápidas |
| Newsletter | Relação owned | Síntese + CTA único |
| Blog / Hub | SEO composto | Pilar indexável |
| Comunidades | Confiança peer | Resposta útil, não spam |
| Email comercial | Conversão | Case + oferta alinhada |

Mesma tese. Ângulos diferentes. Nunca copy-paste cego.

### 4. Cadência de distribuição (semana do pilar)

| Dia | Ação |
|-----|------|
| D0 | Publicar pilar (hub ou YouTube/blog) |
| D0–D1 | Newsletter + post âncora no canal principal |
| D2–D4 | Átomos com ângulos distintos |
| D5–D7 | Clips + engajamento em comunidades |
| D8–D14 | Retargeting orgânico (ângulos não usados) + CTA de captura |
| D30+ | Republish / update do pilar se performou |

### 5. Regras de adaptação

1. **Hook local:** primeiros 2 segundos / 1 linha = dor do ICP naquele feed.
2. **Prova local:** dado, print, demo, quote — o que cabe no formato.
3. **CTA local:** trial, demo, download, reply — um só por peça.
4. **Voz:** fundador/operador > tom de agência genérica.
5. **Anti-spam:** não force a mesma frase em 12 canais no mesmo minuto.

### 6. Medição mínima

- Qual derivado trouxe tráfego / signups / replies do ICP?
- Qual canal converte (não só engaja)?
- Qual ângulo merece virar próximo pilar?
- Owned cresceu (lista, hub, search)?

Vanity sozinho não decide a próxima semana.

## Aplicações

### SaaS

Pilar = playbook do job (ex.: “como reduzir churn no mês 1”). Derivados: clips de UI, carrosséis de checklist, posts de before/after, email de case. CTA = trial ou template no produto.

### IA

Pilar = workflow teardown (input → prompts → output → custo). Derivados: demos curtas, “erros que o modelo comete”, comparativos honestos. Output compartilhável = loop de distribuição.

### B2B

Pilar para champion (como fazer) + versão executive (risco/ROI) como derivados distintos. LinkedIn e email > TikTok genérico. Cases com números > opinião solta.

### Produtos Digitais

Mostre o output do usuário em vários formatos. Template do pilar vira magnet; demos viram Reels; FAQ vira carrosséis. Distribuição = vitrine contínua do produto.

### Startups

1 pilar/semana (mesmo que imperfect). Fundador na distribuição. Prefira 3 canais bem operados a 10 abandonados. Use replies e DMs como canal — não só posts.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Produzir sem derivar | ROI de conteúdo baixo | Matriz 1→N obrigatória |
| Copy-paste multi-canal | Marca preguiçosa | Adaptar hook/CTA |
| Dump no mesmo dia | Fadiga + alcance queimado | Espalhar no ciclo |
| Só vanity | Canal errado “vence” | Atribuir signups/pipeline |
| CTA em todo post idêntico | Treinar ignore | Variar ângulo; CTA claro |
| Terceirizar sem briefing | Ângulos vazios | Brief: tese + ICP + não-dizer |
| Perseguir viral genérico | Audiência errada | ICP first sempre |

## Checklist

- [ ] Existe um pilar por ciclo (não só átomos)
- [ ] Extraímos tese, insights, história, dado e CTA
- [ ] Geramos 8+ derivados adaptados
- [ ] Calendário de distribuição definido (não dump)
- [ ] Cada canal tem intenção clara
- [ ] Owned (email/hub) recebe o pilar
- [ ] Medimos o que traz ICP, não só likes
- [ ] Próximo pilar nasce do ângulo que performou
- [ ] Alinhado a tese do Content Engine
- [ ] Não violamos Positioning / tom da marca

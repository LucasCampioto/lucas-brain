# Competitive Analysis

## Objetivo

Entender rivais e alternativas (incluindo status quo) para escolher onde vencer, o que ignorar e como posicionar — sem virar um clone reativo.

Resolve roadmaps ditados pelo último feature launch do concorrente.

---

## Filosofia

- Seu pior concorrente costuma ser “não fazer nada” ou a planilha.
- Análise serve para decidir. Stack de print screens sem ação é teatro.
- Conheça o rival bem o bastante para respeitá-lo — não para imitá-lo.
- Clientes escolhem sob critérios. Mude os critérios ou vença nos deles.
- Pontos fracos do concorrente só importam se o ICP sente a dor.
- Monitorar ≠ perseguir. Cadência e critérios batem ansiedade.
- Vantagem aparece em wins/losses reais, não em landing pages.
- Transparência interna: time de produto, sales e marketing usam a mesma mapa.

---

## Framework

### 1. Mapa de alternativas

Liste em 4 caixas:

1. **Diretos** — mesma categoria, mesmo job
2. **Indiretos** — outro produto, mesmo budget/job
3. **Status quo** — Excel, agência, processo manual, hiring
4. **Futuros** — big platforms que podem bundlar

Sem status quo, a análise está incompleta.

### 2. Ficha do concorrente (1 página cada)

- ICP aparente e motion (PLG/sales)
- Promessa e categoria reivindicada
- Packaging e preço (faixa)
- Forças reais (distribuição, brand, features, capital)
- Fraquezas observáveis (suporte, complexidade, foco)
- Moat aparente
- Mensagens que usam
- Onde batemos / perdemos hoje (de wins-losses)

Atualize com frequência trimestral; hot rivals mensalmente.

### 3. Matriz de decisão do comprador

| Critério do buyer | Peso | Você | Rival A | Status quo |
|-------------------|------|------|---------|------------|
| Time-to-value | | | | |
| Integrações | | | | |
| Preço / ROI | | | | |
| Trust / segurança | | | | |
| Facilidade | | | | |
| Especialização no job | | | | |

Preencha com evidência de calls, não com wishful thinking.

### 4. Battlecards para vendas

Para cada rival comum:

- Quando aparece
- Armadilha (não atacar feature X)
- Perguntas de diagnóstico
- Diferenciadores honestos
- Prova (case, métrica)
- Landmines (onde perdemos e por quê)

Battlecard mentiroso destrói confiança do AE.

### 5. Processo contínuo

```
Wins & losses estruturados
        ↓
Padrões de objeção e rival
        ↓
Atualizar mapa e battlecards
        ↓
Implicações: posicionamento / produto / preço
        ↓
Uma resposta estratégica (não 20 features)
        ↓
Medir impacto em win rate
```

### 6. Respostas estratégicas (escolha uma)

| Insight | Movimento |
|---------|-----------|
| Rival ganha em brand | Wedge + proof vertical |
| Rival ganha em preço | Valor/ROI ou segmento diferente |
| Rival lento em UX | Velocidade e time-to-value |
| Rival genérico | Especialização / category |
| Rival com distribution | Partner ou canal owned |
| Feature parity race | Parar; engrossar moat |

### 7. Inteligência ética e útil

Fontes: site, pricing pages, G2/reviews, job posts, changelogs, conversas com prospects, demos públicas.  
Evite: engenharia social ilegal, mentir em trials se política da empresa proíbe — prefira open sources e feedback de mercado.

## Aplicações (SaaS, IA, Empresas B2B, Produtos Digitais, Startups)

### SaaS

Win/loss por rival no CRM. Compare onboarding e expansion, não só feature matrix.

### IA

Concorrência inclui foundation models + copilots horizontais. Diferencie no workflow e dados do cliente.

### Empresas B2B

Inclua incumbents e DIY interno. Procurement compara risco. Trust e compliance entram na matriz.

### Produtos Digitais

Rivais + piracy + “grátis no YouTube”. Diferencie resultado e experiência, não só conteúdo.

### Startups

Não mapeie 40 startups. Top 3 diretos + status quo. Foque wins reais.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Feature checklist eterno | Roadmap reativo | Critérios do buyer |
| Ignorar status quo | Mensagem errada | Incluir na matriz |
| Copiar o líder | Sem identidade | Position opposite |
| Battlecards desatualizados | Sales confuso | Cadência trimestral |
| Obsessão com um rival | Ponto cego | Mapa completo |
| Análise sem dono | Morre na pasta | Dono + win/loss loop |

---

## Checklist

- [ ] Alternativas mapeadas (direto, indireto, status quo)
- [ ] Fichas 1-pager dos rivais principais
- [ ] Matriz de critérios do comprador com pesos
- [ ] Win/loss process ativo
- [ ] Battlecards usados por sales
- [ ] Implicações traduzidas em 1 movimento estratégico
- [ ] Preço e packaging comparados com honestidade
- [ ] Moats relativos avaliados
- [ ] Cadência de update definida
- [ ] Time alinhado na mesma narrativa competitiva

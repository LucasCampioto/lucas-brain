# Productivity Systems

## Objetivo

Organizar atenção, energia e trabalho para máxima eficiência do founder — sistemas simples que protegem o deep work e o norte do negócio.

Resolve calendário fragmentado, ferramentas demais e “produtividade” cosmética que não move métricas.

---

## Filosofia

- Produtividade sem norte é hiperatividade.
- Atenção é o bottleneck. Proteja blocos grandes.
- Sistema ruim documentado > sistema genial na cabeça.
- Menos tools, mais hábitos. Stack inchada vira second job.
- Energia > horas. Durma e treine como parte do OS.
- Capture tudo; decida pouco; execute no que importa.
- Automação e templates removem atrito — não substituem julgamento.
- Simplicidade é feature do sistema de trabalho.

## Framework

### 1. Camadas do OS pessoal

```
Norte / OKR da fase
        ↓
Projetos (bets)
        ↓
Próximas ações concretas
        ↓
Calendário (tempo real)
        ↓
Revisão semanal
```

Inbox captura. Calendário compromete. Review governa.

### 2. Regras de atenção

| Tipo de trabalho | Bloco típico | Quando |
|------------------|--------------|--------|
| Deep work (produto, escrita, arquitetura) | 90–180 min | Manhã / pico de energia |
| Comunicação (slack, email, calls) | Batches | 1–2 janelas/dia |
| Operacional (admin, rotina) | Templates | Fixo e curto |
| Estratégico (decisões Tipo 1) | Agendado | Com pré-leitura |

Notificações default = off. Abra canais; não viva dentro deles.

### 3. Sistema mínimo viável (SMV)

Escolha uma ferramenta por função — e pare:

| Função | Exemplo de função |
|--------|-------------------|
| Captura rápida | Inbox única |
| Projetos / tasks | Lista por bet |
| Docs de decisão | 1-pagers |
| Calendário | Única fonte de verdade de tempo |
| Notas de aprendizado | Vault pesquisável |

Critério de troca de tool: o atual quebrou, não “vi no Twitter”.

### 4. Weekly Review (30–45 min)

1. Esvaziar inboxes
2. Atualizar status das bets vs norte
3. Cortar ou adiar o que não serve
4. Bloquear deep work da próxima semana
5. Definir ≤3 outcomes
6. Limpar calendário de reuniões sem dono/decisão

Sem weekly review, o sistema apodrece em 14 dias.

### 5. Templates que multiplicam

Crie uma vez, reutilize sempre:

- Agenda de reunião com decisão esperada
- 1-pager de decisão
- Brief de experiment
- Checklist de ship
- Postmortem curto

Template é leverage de processo. Sem ele, cada semana reinventa a roda.

### 6. Energia como input

| Sinal | Ação |
|-------|------|
| Sono ruim / burnout early | Cortar late meetings e “urgency” falsa |
| Deep work quebrado | Bloquear manhãs; batch async |
| Multitarefa crônica | Uma bet por bloco; phone longe |
| Overcommit social | Quota semanal de calls |

## Aplicações

### SaaS

Separe deep work de produto/PMF de “inbox de cliente”. Suporte escala com macros e docs — não com founder on-call eterno sem sistema.

### IA

Use IA para rascunho, resumo, checklist e research — com revisão humana no que é Tipo 1. Não terceirize julgamento de ICP, preço e ética.

### Empresas B2B

Pipeline e follow-ups pedem CRM simples + cadência. Força bruta de memória = deal lost. Ritual > heroics.

### Produtos Digitais

Calendário de conteúdo e batching de produção. Consistência composta vence sessão heroica quinzenal.

### Startups

No caos early-stage, o SMV evita colapso. Quando o time cresce, o sistema pessoal vira germen do sistema de empresa (Operating Cadence).

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Tool hopping | Reset semanal | SMV estável 90 dias |
| Calendário cheio de calls | Zero deep work | Quota + manhãs protegidas |
| Listas infinitas | Ansiedade | Ligar a bets / norte |
| Sem review | Sistema morto | Sexta/segunda ritual |
| Otimizar input (Pomodoro cosmético) | Norte parado | Outcome-first |
| Dormir mal + “grind” | Decisões ruins | Energia no OS |

## Checklist

- [ ] Norte da fase visível
- [ ] Inbox única de captura
- [ ] ≤3 outcomes da semana definidos
- [ ] Blocos de deep work no calendário
- [ ] Comunicação em batches
- [ ] Stack: uma tool por função
- [ ] Weekly review na agenda (recorrente)
- [ ] Templates para tarefas repetidas
- [ ] Reuniões sem decisão foram cortadas ou recusadas

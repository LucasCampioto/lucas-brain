# Resilience

## Objetivo

Sustentar julgamento e execução sob fracasso, pressão, incerteza e horizontes longos — sem negar a realidade nem romper o time.

Resolve panico estratégico, burnout glamorizado e abandono precoce do que ainda precisava de tempo (ou persistência no morto).

---

## Filosofia

- Resiliência não é aguentar tudo calado. É recuperar capacidade de decidir bem.
- O jogo do founder inclui draws longos e feedback negativo público.
- Dor sinaliza. Ruminação drena. Ação pequena restaura agency.
- Caixa e saúde são infraestrutura de resiliência — não “soft topics”.
- Narrativa honesta > morfina de hype interno.
- Antifragilidade: sistemas que melhoram com estresse (playbooks, buffers, testes).
- Persistência no processo; flexibilidade na hipótese.
- Ego frágil quebra sob critique. Identidade em “aprender + proteger o ativo” aguenta.

## Framework

### 1. Separar tipos de crise

| Tipo | Exemplo | Resposta |
|------|---------|----------|
| Liquidez | Runway curto | Corte de burn, foco em receita/caixa |
| Mercado | Canal morreu / ICP errado | Diagnóstico + experimento |
| Produto | Churn alto | Jobs-to-be-done + fix core |
| Relacional | Conflito cofounder/time | Conversa direta + acordos |
| Pessoal | Burnout, saúde, family | Capacidade first |
| Narrativa | Vergonha / pressão social | Fatos vs história |

Errar o tipo → remédio errado (ex.: hire sob crise de caixa).

### 2. Protocolo 24–72h (quando o golpe chega)

```
Parar o drama coletivo
        ↓
Fatos em uma página (caixa, métricas, opções)
        ↓
Estabilizar oxigênio (runway / moral mínimo)
        ↓
1–3 ações de agency nas próximas 72h
        ↓
Comunicar com clareza (sem theatre)
        ↓
Review: o que muda no sistema?
```

### 3. Buffers que compram resiliência

| Buffer | Função |
|--------|--------|
| Runway (meses) | Tempo para aprender |
| Margem operacional | Absorve choque |
| Processo documentado | Empresa não depende só do humor |
| Relacionamentos de confiança | Conselho e deals |
| Saúde física / sono | Qualidade de decisão |
| Diversificação leve de canal | Menos single point of failure |

Resiliência sem buffer é romanticismo.

### 4. Persistência vs teimosia

| Persistência | Teimosia |
|--------------|----------|
| Kill criteria claros | “Mais um mês” eterno |
| Dados novos atualizam aposta | Ego protege a aposta |
| Processo consistente | Resultado cosmético |
| Aprende em público interno | Esconde métrica |

Escreva kill criteria *antes* do stress — sob pressão o cérebro racionaliza.

### 5. Higiene sob pressão (não-negociáveis)

- Sono e movimento mínimos
- Uma conversa honesta por semana (cofounder/mentor)
- Dashboard de oxigênio: runway, burn, pipeline, retenção
- Recusar urgência falsa que destrói deep work
- Postmortem curto após cada golpe (sem ritual de vergonha)

## Aplicações

### SaaS

Churn spike ou outage: comunique, remedia, previna. Resiliência = on-call playbook + status transparente — não “founders heroics” toda madrugada sem root cause.

### IA

Model drift, custo, alucinação pública: resiliência opera com evals, fallbacks e limites. Crash de confiança é mais caro que o bug técnico.

### Empresas B2B

Deal perdido / budget freeze: pipeline diversified e relacionamento contínuo. Conta única = fragilidade.

### Produtos Digitais

Algoritmo muda, viral some: ativo próprio (email, produto, comunidade) é amortecedor. Resiliência de distribuição.

### Startups

Near-death é comum. O padrão: encolher, clarificar ICP, voltar a evidência. Fundraising como único plano B é fragilidade estratégica.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Toxidade positiva | Problema escondido | Fatos + opções |
| Grind sem buffer | Colapso | Runway + saúde |
| Teimosia | Queima caixa | Kill criteria pré-escritos |
| Isolamento | Decisão pior | Conselho / cofounder sync |
| Panic hire / panic pivot | Dívida | Protocolo 72h |
| Identidade = valuation | Quebra emocional | Identidade = processo + aprendizado |

---

## Checklist

- [ ] Sei qual tipo de crise estou enfrentando
- [ ] Fatos e opções cabem em 1 página
- [ ] Oxigênio (caixa/saúde) estabilizado primeiro
- [ ] Há 1–3 ações de agency em 72h
- [ ] Kill criteria das bets principais existem
- [ ] Buffers revisados (runway, canal, processo)
- [ ] Comunicação honesta feita às pessoas certas
- [ ] Postmortem virou mudança de sistema
- [ ] Não-negociáveis de sono/movimento respeitados

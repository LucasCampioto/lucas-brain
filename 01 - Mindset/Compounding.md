# Compounding

## Objetivo

Desenhar o negócio para crescimento composto — onde ganhos de hoje aumentam a base de amanhã — em vez de corridas lineares que reiniciam todo mês.

Resolve a obsessão por picos (campanhas, hacks, “mês recorde”) que não deixam residual.

---

## Filosofia

- Compounding exige base estável + taxa de reinvestimento + tempo.
- Retenção é o juro do negócio. Aquisição sem retenção é depósito que vaza.
- Consistência vence intensidade esporádica.
- Ativos compoundam; atividades one-off consomem.
- Pequenas melhorias no core (ativação, churn, margem) batem big bangs cosmética.
- Feedback loops positivos bem desenhados > mais budget.
- Early compounding parece lento. Depois parece “óbvio” só para quem plantou.
- Complexidade mata compounding: espalhar esforço dilui a taxa.

---

## Framework

### 1. Equação simples

```
Base (clientes / conteúdo / dados / reputação)
        ×
(1 + taxa de melhoria / reinvestimento)
        ×
Tempo
        −
Vazamentos (churn, dívida, diluição de marca)
        ↓
Valor composto
```

Sem base e sem tempo, taxa alta é ilusão.

### 2. Onde compoundar (escolha 1–2 motores)

| Motor | O que acumula | Métrica de taxa |
|-------|---------------|-----------------|
| Produto | Uso, hábito, switching cost | Retention / expansion |
| Conteúdo | Índice, autoridade, SEO | Tráfego orgânico qualificado |
| Dados | Modelos, relevância | Qualidade → retenção |
| Rede | Densidade de usuários | Valor por membro |
| Marca | Preferência, pricing power | Win rate / premium |
| Capital | Reinvestimento com payback | CAC payback + LTV |
| Skill org | Playbooks, velocidade | Cycle time / qualidade |

### 3. Desenhe o reinvestimento explícito

Todo motor precisa de: **output → reentra como input**.

Exemplos:

- Usuário ativado → convida / gera case / deixa review
- Receita → paid só em canais com payback + funil saudável
- Conteúdo → próximo conteúdo com base em demanda real
- Aprendizado de suporte → vira doc / automação / fix de produto

Se o output não volta, você tem funil — não compounding.

### 4. Mate os vazamentos primeiro

```
Medir churn / abandono / margem
        ↓
Tapar vazamento do core
        ↓
Aumentar taxa (ativação, expansão, conteúdo)
        ↓
Aumentar base (aquisição)
```

Escalar aquisição com vazamento alto é acelerar o buraco.

### 5. Ritmo composto (operacional)

| Ritmo | Ação |
|-------|------|
| Diário/semanal | Ship no motor escolhido (não em 10 frentes) |
| Mensal | Taxa: retention cohorts, expansão, orgânico, margem |
| Trimestral | Dobrar o que compoundou; matar o linear barulhento |
| Anual | Inventário de ativos: o que ficou mais valioso sozinho? |

## Aplicações

### SaaS

Expansion revenue e net revenue retention são compounding clássico. Invista em aha moment, seats, usage, success — não só top-of-funnel.

### IA

Cada interação pode melhorar o sistema (com privacidade e design certos). Dados de domínio + avaliação contínua = moat que compounda; wrapper estático de API não.

### Empresas B2B

Base instalada bem servida gera upsell, referência e case. Custom caótico na base destrói margem e velocidade — anti-compounding operacional.

### Produtos Digitais

Biblioteca de conteúdo + produto que melhora com uso. Um hit viral sem hábito é spike; série consistente com retenção é juros.

### Startups

Escolha cedo o motor primário. “Um pouco de tudo” espalha a taxa e parece busy. Compounding exige foco chato e longo.

## Erros Comuns

| Erro | Efeito | Correção |
|------|--------|----------|
| Hack do mês | Zero residual | Motor único + ritmo |
| Aquisição sem retenção | Queima capital | Consertar cohort primeiro |
| Multiplicar canais cedo | Taxa diluída | 1 loop dominante |
| Mudar de estratégia todo quarter | Quebra a curva | Tese + paciência medida |
| Ignorar margem | Cresce quebrado | Unit economics no scorecard |
| Complexidade de produto | Churn e custo | Simplificar core job |

---

## Checklist

- [ ] Escolhi 1–2 motores de compounding (não 7)
- [ ] Reinvestimento do output está desenhado
- [ ] Vazamentos (churn/abandon/margem) medidos e atacados
- [ ] Há métrica de “taxa” além de volume
- [ ] Semana protege o motor (tempo bloqueado)
- [ ] Matei iniciativas lineares que só geram drama
- [ ] Review mensal de cohorts / ativos
- [ ] Horizonte de paciência explícito (sem ser desculpa)
